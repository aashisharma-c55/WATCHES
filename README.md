# ⌚ WATCHES

A simple and responsive **Watches Website** created using **HTML and CSS**.
The project is designed to showcase different watches with a clean and attractive web interface.

## 🌐 Live Demo

[View Website](https://aashisharma-c55.github.io/WATCHES/)

## 📌 About the Project

**WATCHES** is a front-end web development project created to practice and demonstrate the use of **HTML and CSS**.

The website presents watches in an organized and visually appealing layout. It focuses on basic web design concepts such as images, navigation, styling, spacing, colors, and responsive layouts.

## ✨ Features

* ⌚ Watch product showcase
* 🎨 Clean and attractive user interface
* 📱 Responsive webpage design
* 🖼️ Watch images and product sections
* 🧭 Navigation section
* 💻 Built using basic front-end technologies
* 🌐 Can be hosted using GitHub Pages

## 🛠️ Technologies Used

* **HTML5** – Structure of the website
* **CSS3** – Styling and layout
* **GitHub Pages** – Website deployment

## 📂 Project Structure

```text
WATCHES/
```

## 🚀 How to Run the Project

1. Clone the repository:

```bash
git clone https://github.com/aashisharma-c55/WATCHES.git
```

2. Open the project folder.

3. Open `index.html` in your browser.

That's it! The website will run locally.
